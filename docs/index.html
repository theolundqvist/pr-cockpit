CLI

Listen, don’t poll.

The installer adds the open-source pr-cockpit CLI. Reads are served from the local cache, so they return fast in agent-shaped form and only touch GitHub when that cache has actually gone stale.

listen blocks until substantive cached state changes, so agents skip the repeated gh polls that spend GitHub calls and tokens re-reading a quiet PR.

  • pr-cockpit owner/repo#N · state, checks, unresolved threads
  • --diff · the cached diff
  • --file path · a full file at the PR head
  • resolve HANDLE · resolve a review thread
  • update · fast-forward and rebuild the installed app

Install

One command.

Checks the macOS prerequisites, installs the app, and opens setup. A legacy private install is replaced; local PR data and settings stay.

Rerun the same command to upgrade.
