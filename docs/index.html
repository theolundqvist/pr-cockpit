How it works

The network moves off the critical path.

GitHub webhooks trigger targeted refreshes as changes happen. A local Bun server keeps the result on disk and echoes your writes immediately, so the interaction never blocks on GitHub.

The live experience: configure the relay whether you work solo or with a team. GitHub changes reach your cockpit in seconds instead of waiting for the next poll.

The dependable base layer: the relay is off until configured. The 3-minute poll still handles cold starts, missed events, and reconciliation.

Install

One command.

The installer checks for bun and gh, asks before installing anything, clones to ~/.pr-cockpit, builds the UI, creates ~/Applications/PR Cockpit.app, registers deep links, and sets up launch at login.

On first run the app walks you through GitHub access, picking repos, and turning on live updates. Until the webhook relay is connected, the poller keeps the local cache correct.

macOS only. Rerun the same command to upgrade.

$ curl -fsSL https://raw.githubusercontent.com/theolundqvist/pr-cockpit/main/scripts/bootstrap | bash
