Before you install

A few useful details.

Does this replace GitHub?

No. GitHub remains the source of truth. PR Cockpit is a local workspace for reading and acting on your pull requests. Comments, reviews, edits, and merges are sent back through your authenticated GitHub CLI login.

How does the local cache stay current?

Webhook markers trigger targeted refreshes from GitHub, and a poller repairs missed events. The app reads from the refreshed local cache; it does not need to rebuild each screen from GitHub. Initial sync and uncached data still need to be fetched.

What goes through the live-update relay?

The relay carries change markers and compact Actions run and job state, including runner assignment—not full pull-request payloads or job logs. Hosted team sync is enabled by default on new installs. You can point the app at your own relay; see the self-hosting guide.

What should Linux users know?

The installer sets up the app, a user service, a desktop entry, tray integration, and the prcockpit:// handler. X11 is supported directly; Wayland sessions use XWayland, and global shortcuts depend on compositor policy. The installer checks system prerequisites before proceeding.

How do I update or remove it?

Run pr-cockpit update to upgrade. On Linux, run $HOME/.pr-cockpit/scripts/uninstall to remove the app; add --purge to remove local data too. See the installation documentation for current platform details.
